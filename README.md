# 🚜 Бульдозер 2/2 — Календарь смен и зарплата (8 разряд)

Специализированное приложение для машиниста бульдозера с реальным графиком два через два: **2 дня день → 2 дня отдых → 2 дня ночь → 2 дня отдых**.

---

## 📅 График смен (Цикл 8 дней)

Цикл повторяется каждые 8 дней:
1. ☀️ **1-й День** — Дневная смена (11.5 ч, 0 ночных)
2. ☀️ **2-й День** — Дневная смена (11.5 ч, 0 ночных)
3. ☕ **Выходной** — Отдых
4. ☕ **Выходной** — Отдых
5. 🌙 **1-я Ночь** — Ночная смена (11.5 ч, из них **8 ч ночные** с 22:00 до 06:00)
6. 🌙 **2-я Ночь** — Ночная смена (11.5 ч, из них **8 ч ночные**)
7. 🛌 **Отсыпной** — Отдых после ночи
8. ☕ **Выходной** — Отдых

## 💰 Расчётные параметры машиниста бульдозера (8 разряд)

* **Тарифная ставка**: `185.00 ₽ / час` (editable в настройках)
* **Норма часов в месяц**: `176 часов`
* **Длительность смены**: `11.5 часов`
* **Ночные часы**: `8 часов` за каждую ночную смену (доплата **+40%**)
* **Доплата за вредность**: **+8%** ко всем часам
* **Районный коэффициент (РК)**: **1.3** (или 1.6 по региону)
* **Сдельный приработок / КТУ**: ~65 000 ₽ (editable)
* **НДФЛ**: 13%
* **Средняя ставка на руки**: **~750 ₽ / час**

## 📲 Как установить на Android за 30 секунд

1. Перекиньте файл **[index.html](file:///c:/ShiftCalendar/index.html)** на телефон (через Telegram в «Избранное», провод или облако).
2. Откройте его на телефоне в **Google Chrome** (или Samsung Internet).
3. Нажмите меню браузера (**три точки ⋮**) и выберите **«Установить приложение»** (или «Добавить на главный экран»).
4. Android автоматически установит полноценное приложение со своей иконкой на рабочий стол, которое работает на весь экран и 100% автономно без интернета.
